Retail Sales Prediction System

Aug 2025 - Dec 2025 | Group Project — Team Leader

🔗 View on GitHub

Project Overview

An end-to-end XGBoost sales forecasting pipeline built on 58.5 million rows of real-world retail data. As team leader, I directed the project from data ingestion through to deployment-ready, store-specific forecasting models, achieving strong predictive performance across all 10 store segments.

58.5M Rows of Retail Data

0.88 Average R²
10 Store Segments

Key Features

🧹 Data Cleaning & Reshaping

Cleaned and reshaped raw retail data from wide to long format to prepare it for large-scale feature engineering and modelling.

🛠️ Feature Engineering

Engineered lag variables, event indicators, pricing flags, and calendar effects to capture the seasonal and promotional dynamics driving retail demand.

🌲 Store-Specific XGBoost Models

Trained and hyperparameter-tuned individual XGBoost models per store segment, reducing inter-store prediction variance and improving generalisation.

👥 Team Leadership

Led the group project end-to-end, coordinating data ingestion, modelling, and evaluation workstreams across the team.

Technical Stack

Python XGBoost pandas NumPy Feature Engineering

The project leveraged pandas and NumPy for large-scale data wrangling on tens of millions of rows, with XGBoost powering the store-specific gradient-boosted forecasting models. GitHub and Kaggle versions were used for version control throughout development.
